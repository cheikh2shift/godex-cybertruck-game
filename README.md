# Cybertruck Infinite Run

A fast-paced 3D endless runner featuring the Tesla Cybertruck racing through a neon-lit cyberpunk highway. Dodge enemies, collect power-ups, and see how far you can go!

## Gameplay

- **Controls**: Arrow keys or A/D to switch lanes
- **Power-ups**:
  - **S** - Shield: Temporary invincibility
  - **B** - Boost: Speed burst
  - **W** - Slowmo: Slow down time
  - **M** - Magnet: Attract nearby power-ups
- **Touch**: Swipe left/right on mobile

## Features

- Procedurally generated road with increasing difficulty
- Dynamic difficulty scaling based on score
- 4 unique power-up types
- Cyberpunk visual style with neon effects
- Particle trail effects that change color with active power-ups
- Roadside decorations (trees and buildings)
- Camera tilt on lane changes

## How to Play

1. Open `index.html` in a browser
2. Click "START" to begin
3. Dodge incoming vehicles by switching lanes
4. Collect power-ups to build your arsenal
5. Use collected power-ups strategically with keyboard shortcuts
6. Survive as long as possible and beat your high score!

## Tech Stack

- Three.js for 3D rendering
- Vanilla JavaScript
- WebGL

## Browser Support

Works best in Chrome, Firefox, and Edge. Requires WebGL support.
